# chengshu-blog-discussions

Public GitHub Discussions store for [blog.chengshu.space](https://blog.chengshu.space) comments via [Giscus](https://giscus.app/).

Blog source stays in `skadai/skadai.github.io` (may be private). This repo is **public** so visitors can read and post discussions.

## Setup checklist

1. Repo Settings → General → Features → enable **Discussions**
2. Install the [giscus GitHub App](https://github.com/apps/giscus) on **this repo only**
3. Prefer a Discussions category with type **Announcements** (e.g. name `Announcements`) for giscus
